# 回响之刃 Echo Blade

一个使用 Python 3.12+ 和 Pygame 2 开发的 2D 像素动作 Roguelike 原型。

世界背景、超常现象、角色能力与剧情主线详见 [世界观设定集](worldbuilding.md)。

## 启动

PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python main.py
```

如果 PowerShell 不允许执行脚本，也可以直接运行：

```powershell
.\.venv\Scripts\python.exe main.py
```

## 当前完成

- 1280x720 逻辑画布与可调整窗口
- 使用 `images/` 内像素素材搭建开始界面
- 键盘方向键/WASD 选择，Enter/Space/J 确认
- 鼠标悬停与点击菜单
- 本地排行榜占位窗口
- 设置窗口：音量与辅助模式
- 退出确认提示
- 六个存档位：`开始游戏` 与 `继续游戏` 都会列出全部六格存档，空位可直接新建，已有存档点两次确认后覆盖；`继续游戏` 载入所选档案（若该档案还没走完新手教程，会接着继续教学）
  - 新建存档会把角色等级、成长树、关卡进度与分数全部重置，并重新走一遍新手教程
  - 存档文件里设置是全局共享的，进度按槽位分开保存；旧版单档案存档会自动迁移到 1 号存档位，不会丢进度
- `game.entities.enemies` 提供敌人基类与 5 种普通敌人子类，房间生成可直接实例化具体敌人
- `game.entities.player` 提供按时间步更新的移动、跳跃与三段普通攻击
- 操作：`A/D` 移动、`Space` 跳跃、`J` 攻击、`K` 弹刀、`L` 冲刺、`U` 回响剑气；配合 `W/↑` 或 `S/↓` 可使用上劈与下劈
- 下劈命中敌人后会向上弹起，连续命中可维持滞空
- 初始关卡包含移动、跳跃、基础攻击、上劈、下劈、弹刀、回响能量与回响剑气的新手引导，完成教学后才会开启房间结算
- 教学步骤只需按提示做出对应动作即可通过，不要求攻击命中、下劈命中或成功触发完美弹刀；能量教学挥砍一次后会直接补满能量，让你按 `U` 完整释放一次剑气
- 完成新手教程后进入灰塔大厅；大厅只有三个入口：左侧「回响中枢」、中间「远征城门」、右侧「远征排行」，鼠标移到图标上会放大
- 一局从第一阶段第一关开始，依次闯过第一阶段 5 关与第二阶段 7 关，直到生命归零或击破第二阶段首领；每局等级都从 1 级重新累积，失败不会保留成长
- 点中间的远征城门会先播放漩涡过场（漩涡由小变大吞掉画面 → 黑屏 → 从中心圆形展开关卡）；存在暂存远征时会先选择「继续当前远征」或「放弃暂存并重新开始」，继续时保留生命、等级、经验、击败数、战时铸币、回响能量与商店强化
- 暂存会保存路线种子、关卡类型和事件是否已结算；恢复战斗关时重新开始当前遭遇，但事件奖励不能重复领取，生命归零或第二阶段通关后清除暂存
- 正式远征中可从设置选择「暂返大厅」：系统立即刷新暂存并回到灰塔大厅；放弃暂存只删除本局状态，不影响回响遗晶、回响中枢节点和历史战绩
- 每次一局结束都会停在结算界面，列出本局抵达关卡、获得技能点（回响遗晶）、击败敌人数、完美弹刀、最高连击与分数；通关时标题为「第二阶段 · 通关」
- 生命归零进入死亡勘定：根据本局分数、抵达层数、最高连击和完美弹刀逐项凝结回响遗晶，并计入排行；结算只写入一次当前存档
- 回响中枢改成三条谱系、每条谱系下若干分级分支：点谱系标题或左右键折叠/展开，点分支选中后用「升级」按钮逐级点亮
  - 基元谱系：生命晶格（+100/200/300/400/500 生命）、锋刃淬炼（+5/10/15/20/25 攻击）、谐振增幅（+10%~50% 剑气伤害），每级消耗翻倍
  - 机制谱系：疾影闪避（解锁冲刺）、凌空复写（解锁二段跳）、生命自愈（战斗房内每 10 秒回 3/6/9/12/15 生命）、谐振回流（每秒回 1/2/3/4/5 回响能量）
  - 铸币谱系：开局行囊（开局 +5/10/15/20/25 铸币）、战利议价（击破铸币 +5%~25%）、风险契约（点亮后每局开局可选「高压远征」：敌人更强、遗晶 ×1.5）
  - 技能树按存档保存，战斗失败不会重置，只有新建或覆盖存档才会清空
- `generate_gameplay_assets.py` 可生成战斗原型所需玩家、敌人、首领、投射物、HUD 和奖励素材
- `sounds/` 内含大厅与战斗两首循环背景音乐，以及脚步、跳跃、冲刺、挥刀、命中、敌人起手、受击、弹刀、敌人登场、传送门开启与进入等 19 个音效
- 进入关卡（含新手教学关卡）自动交叉淡化到战斗音乐，返回菜单、大厅与结算界面恢复大厅音乐
- 音乐与音效分总线混音：战斗音乐让出确认感频段，弹刀、命中、受击会短暂压低音乐
- `generate_audio_assets.py` 可重新生成全部音乐与音效（纯 Python 标准库），支持 `--preview` 试听
- 音频规格与触发映射见 `audio_design.md`
- 闪避（`L` / `Shift`）：约 70px 位移，0.3 秒内置冷却，冲刺期间无敌，并留下青色残影拖尾
  - 闪避需要先在回响中枢的机制谱系点亮「疾影闪避」；教学关内始终可用
- 完美弹刀提示：近战敌人命中前 0.65 秒亮起金色闪光，闪光期间按 `K` 即为完美弹刀；首领招式可以使用更短的专属窗口（冠冕三裁 0.4 秒、断忆敕令 0.35 秒），提示闪光会同步收紧
- 弹刀内置冷却：架势收招后还有 0.2 秒不能再次弹刀，无法靠连按把攻防节奏无缝覆盖过去
- 远程弹刀：子弹进入角色身边约 170px 范围内按 `K` 即可弹开，**子弹会原样反弹回射击者并在命中时结算伤害**
- 进入新关卡不会秒刷怪：先显示「敌影接近」倒计时面板（跳动秒数 + 进度条，最后 1 秒转红），3 秒后敌人登场并播放登场音效
- 敌人登场后还会先观察 1 秒才开始出手，不会一刷出来就贴脸攻击，留出反应与站位时间
- 角色基础生命上限提升到 320（原为 100），左上角生命条直接显示 `当前 / 上限` 数值，残血时整条泛白提醒
- 第一阶段现已贯通五层；前三层为三波常规战，波与波之间用「第 N 波敌影」倒计时等待（2.6 秒），当前波全部清空后才排下一波
  - 第一层「锈蚀中庭」：追击者 + 投矛手，三波规模逐波扩大
  - 第二层「镜面回廊」：加入盾卫，正面推进 + 贴身压制 + 远程消耗的组合
  - 第三层「裂隙深庭」：加入裂隙虫与共鸣法师，出现不可弹反突进与延迟弹幕
  - 第四层「余烬行商驿站」：使用沿途积累的战时铸币购买生命上限、攻击或能量强化，并可用 18 铸币反复购买「凝血汤剂」回复 60 点生命
  - 第五层「锈冠王庭」：挑战两阶段首领锈冠骑士；常驻减免 80% 伤害，需要连续弹开三段「冠冕三裁」才能击退破防；两个阶段的常规攻击都是三段冠冕三裁，破防恢复后不会退回单发横斩；进入二阶段的瞬间就会放一次「断忆敕令」，之后按「打完一套连段 → 插入一次敕令」交替推进
- 第二阶段共七关，并加入精英讨伐、失真记忆事件、遗珍回廊、静滞庇护所与紊乱裂隙等关卡样式
  - 第 1、3 关为三波高密度战斗，每波 4～5 名敌人；第 4 关为三波精英讨伐，第 5 关为事件关
  - 第 2 关按本局路线种子从事件、奖励、休整、精英和裂隙中随机抽取；暂存后不会重抽
  - 第 6 关固定为余烬行商商店（凝血汤剂同样可重复购买），第 7 关固定为断桥司钟，击破后进行总结算
  - 奖励和休整关提供三项互斥选择，事件关提供四项（多一条「回溯愈合」，按最大生命 40% 回血）；确认后立即保存；精英与裂隙关清场会获得额外战时铸币
- 奖励与休整关不会恢复当前生命；主动回血有两条途径：事件关的「回溯愈合」（最大生命 40%，生命已满时拒绝选择）与行商驿站可重复购买的凝血汤剂。增加生命上限时当前生命保持不变
- 生命自愈只在战斗房内生效，每 10 秒结算一次；升级和进入下一关不再回血
- Boss 发动「断忆敕令」时会先瞬移到距离玩家最远的场地边缘，再开始全场预警
- 「断忆敕令」覆盖全场且不能用冲刺无敌规避：未完美弹刀会损失 80% 当前生命；成功弹刀则触发弹反冲击波，令首领瘫痪 5 秒且减伤失效
- 首领抗性：锈冠骑士常驻减免 80% 伤害（弹反伤害同样被减免），只有破防的 5 秒窗口内不减免；破防瞬间额外承受最大生命 10% 的伤害
- 第二阶段第 7 关的断桥司钟以「时钉散射」连发三枚可弹反弹幕；核心未暴露时任何攻击都只削韧性不掉血，韧性清空后核心暴露 4 秒才是输出窗口
- 韧性系统：把敌人韧性打空只会进入短暂「破绽」（首领为 1.2 秒「核心暴露」），窗口内不再重复累计、窗口结束韧性回满，敌人会重新起身进攻，不会被打成永久僵直
- 受击反馈：角色与敌人被打中时整体泛白闪烁，弹刀时敌人闪烁更亮并被向后震开一段距离（首领只后退一小步）
- 敌人倒下动画：被击败的敌人先向一侧倒下，再慢慢淡出消失，而不是立刻从画面里消失
- 近战敌人会主动贴近角色，但会停在身前不再与角色重叠；角色永远画在最上层，不会被敌人遮住
- 战斗界面去掉了多余的浅色描边方框，血量、能量、铸币与首领血条都只保留色块本身
- 进入每一层会先弹出关卡简报；战斗层介绍攻击方式，商店层介绍交易规则，按 `Enter` / 空格 / 鼠标左键继续
- 等级与经验：角色初始 1 级，击败敌人按种类与层数给经验，升级所需经验逐级提高（60 / 111 / 174…）
  - 升级提高生命上限 +26 与攻击力 +3（普通攻击与技能同时受益），但不恢复当前生命
  - 等级与经验在本局内跨层保留，左上角有独立的经验条与 `Lv.N` 数值显示
- 回响能量：新远征开局为 0，上限 100，进入下一关时保留当前能量；普通攻击 +4、上劈/下劈 +7、击败敌人与完美弹刀各 +20，跳跃、冲刺与移动不产生能量
  - 能量满时角色身上闪白光提示，左上角能量条转白并显示「剑气就绪」
- 回响剑气还在场上时不会积攒任何回响能量（技能动作结束、剑气消失后才恢复积攒），避免一发剑气滚出下一发
- 回响剑气（`U` 键，可在设置中改键）：能量满时才能释放
  - 模型保持原来那版：一道比角色略大一圈（约 148 高）的竖向白色半月，带残留辉光
  - 攻击范围贯穿全屏：以 900 px/s 一路斩到画面另一侧才消失，飞出画面后才淡出，中途不掉亮度也不会半路停下
  - 伤害为普通攻击的 300%，命中后把敌人击飞（横向推开 + 腾空再落地）并使其进入破绽
  - 释放期间角色无敌，剑气会斩灭沿途碰到的敌方子弹
- 关卡界面右上角有小齿轮设置图标，按 `Esc` 或点击图标打开设置，里面可以调音量、改按键、开关辅助模式与全屏，也可暂存远征后返回大厅或返回主菜单（后者会先弹确认）
- 「远征排行」记录每局的抵达进度，并显示击败数、弹刀次数、连击与分数；完成第二阶段第 7 关后进入通关结算
- 关卡不再有「完成关卡 / 返回主菜单」按钮：完成战斗或事件后屏幕最右侧出现「回响之门」，第一阶段第 5 关通往第二阶段，第二阶段第 7 关通往总结算
- 角色与敌人都可以在整块战斗区内左右自由移动，只被画面边界挡住
- `generate_portal_assets.py` 可重新生成传送门待机与进入动画素材（96×160 像素画）
